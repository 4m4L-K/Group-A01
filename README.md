Selected Theme

The selected theme for this project is a Biography-Based Website.
The website is designed to present the complete life story of a selected individual in a structured, visually appealing, and user-friendly manner. The theme focuses on storytelling through digital design by organizing personal details, achievements, career milestones, and life events into well-defined sections.

The design approach follows clean UI principles, readability, visual hierarchy, and responsive layout to ensure a good user experience across devices.

Purpose of the Website

The main purpose of the website is:
	•	To digitally present a person’s biography in an organized format
	•	To provide users with easy access to detailed life information
	•	To demonstrate UI/UX design principles learned in the User Interface Design course
	•	To apply front-end development skills (HTML, CSS, JavaScript)
	•	To create a responsive and visually attractive web interface

This project also aims to transform traditional text-based biography content into an interactive web experience.


Target Audience

The target audience for this website includes:
	•	Students researching about the person
	•	Teachers and academic users
	•	General public interested in learning about the individual
	•	Website design evaluators (faculty)

The interface is designed to be simple and accessible so that users of different age groups can navigate it easily.

Sitemap / Website Structure

The website consists of the following major pages and sections:

Home Page
Early Life & Education
Career Journey
Achievements & Awards
Gallery
Timeline
Contact / Feedback Page

A top navigation menu is provided on all pages to allow smooth and quick navigation throughout the website.

Detailed Description of Pages
1. Home Page

The Home Page acts as the main landing page of the website.

Main Elements:
Name and profile image of the selected individual
Attractive hero/banner section
Short biography introduction
Navigation menu
Quick-access buttons to important sections
Background visuals and modern typography
Purpose:

The purpose of the home page is to create a strong first impression and provide users with a quick overview of the individual’s identity and importance.

2. Early Life & Education Page

This section provides detailed information regarding the person’s childhood and educational background.

Included Information:
Date and place of birth
Family background
Childhood experiences
School education
College/university education
Early inspirations and important life events
Purpose:

To help users understand the foundation and formative years of the individual’s life.

3. Career Journey Page

This page explains the professional growth and major career milestones of the individual.

Included Information:
Initial career steps
Important positions held
Major projects or contributions
Professional achievements
Career growth timeline
Impact in their field of work
Purpose:

To present the development of the individual’s professional life in a clear and organized manner.

4. Achievements & Awards Page

This page highlights the recognitions, awards, and accomplishments received by the individual.

Included Information:
National and international awards
Honors and recognitions
Major accomplishments
Contributions to society or industry
Special achievements and records
Purpose:

To showcase the success and influence of the selected individual.

5. Gallery Page

The Gallery Page visually represents important moments from the individual’s life.

Features:
Image collection
Photo grid layout
Slideshow or carousel
Image captions
Event-based photographs
Purpose:

To improve user engagement through visual storytelling.

6. Timeline Page

The Timeline Page displays important life events in chronological order.

Features:
Interactive vertical or horizontal timeline
Event dates and descriptions
Milestones visualization
Structured life progression
Purpose:

To help users easily understand the sequence of important events throughout the person’s life.

7. Contact / Feedback Page

This page allows users to provide feedback or contact the website administrators.

Included Components:
Contact form
Name field
Email field
Message field
Submit button
Basic form validation using JavaScript
Social media links (if applicable)
Purpose:

To improve communication and user interaction with the website.
